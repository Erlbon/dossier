Dossier 0.10: the cursor stays where you were after a move, columns fit the panel, drag and drop within one panel works again, and the groundwork for a Mac and a Linux build.

**Two downloads.** `dossier-setup.exe` installs Dossier for you alone (no administrator rights, `%LOCALAPPDATA%\Programs\Dossier`) and starts in under a second. `dossier.exe` is the one-file program: nothing to install, but it unpacks itself at every start and takes about three seconds. Windows 10 or 11. Settings stay in your user profile (`dossier.ini`); 0.9 settings carry over.

## What is new since 0.9

- **After a move or a delete the cursor stays in place**, on the next item, instead of jumping to the top of the folder. Settings > Keep Cursor Position After Moving or Deleting switches it off.
- **View > Fit Columns to Panel** (on by default): Name takes the slack, so widening another column narrows Name and every column edge stays on screen. Also on the column header's right-click menu.
- **The frosted background keeps the colours behind it** in the light scheme, instead of a flat grey.
- **A change of case or accent spelling only** (`Beach.JPG` to `Beach.jpg`) renames on a USB stick or other disk that ignores case, not only on the Windows drive itself.
- **The notepad's block selection** (Alt+drag, Alt+Shift+arrows) always uses a really fixed-width font, so the block stays a straight rectangle.

## Fixed

- **Dragging a file onto a folder in the same panel** did nothing when the drag started in that panel. It lands again.
- **PyQt6 6.12 has no PDF module**: Dossier is held below it, so a fresh install still has the PDF viewer and PDF thumbnails.
- **A tar opened through 7-Zip** no longer lists 7-Zip's `@PaxHeader` entries as files.

## Things to know

- **Coming from 0.9:** Help > Check for Updates does it.
- The exe and the installer are not code-signed, so SmartScreen may ask the first time.
- **Mac and Linux:** the tests now run on macOS and Ubuntu too, and test builds of a Mac app (Apple Silicon, unsigned) and a Linux tarball are made separately for testers. They are not part of this release yet.

Every change, build by build, is in [CHANGELOG.md](https://github.com/Erlbon/dossier/blob/main/CHANGELOG.md).
