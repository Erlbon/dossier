First public release of Dossier: a dual-pane file manager for Windows.

**Download `dossier.exe`**, one file, nothing to install. Windows 10 or 11. It keeps its settings in your user profile (`dossier.ini`), never in the registry. Linux and macOS: run it from a checkout (see the README); a Linux build is not part of this release.

## What is in it

- **Two panels with tabs and one shared selection**, the F-key bar, a command line, drag and drop, the clipboard.
- **Safe changes:** every copy, move, rename and delete is planned and shown first; a name that is taken is asked about; copies can be read back and compared; renames and same-drive moves can be undone.
- **A Home page** with drives (with lights), places, pinned folders, network shares, servers and the devices of your Tailscale network.
- **Servers as folders:** SFTP, SCP, WebDAV, FTP and FTPS, and read-only OPDS book catalogues and Subsonic music servers. Logins go to the system's password store, only if you ask; certificates and host keys are shown and pinned.
- **Archives as folders** (zip, 7z with 7-Zip, and more); change a zip in place, pack, unpack, convert.
- **Search, duplicate finder, compare and synchronize, batch rename, checksums, saved selections, folder sizes.**
- **Viewer** for text (any size and encoding, column selection), pictures with EXIF, hex and Markdown; **editor**; **Properties and columns** that read the tags inside music, comic and video files; **tags on files**.
- **Folder notes** shown under the listing, and **folder layouts** that remember how each folder is shown.
- **A command line** in the same exe (`dossier ls`, `find`, `copy`, `dups`, `compare`...; `--dry-run`, `--json`) and **a local MCP server** (`dossier mcp`) so an AI assistant can look at your files and propose changes that only you can approve.
- **Your look:** light, dark or the system's scheme, two icon sets, fonts, bold on or off; the programs bar, the function key bar and the command line can be dragged to where you want them.

## Things to know

- The remote servers (SFTP, SCP, WebDAV, FTP, OPDS, Subsonic) have been tested against test servers and Git's `sftp-server`, not against many real ones. Please report what a real server does differently.
- A file inside a catalogue or archive opens by being downloaded first, then handed to the program Windows has for it. Nothing streams.
- 7z archives need 7-Zip installed (or `py7zr` when run from a checkout). RAR and the other formats need 7-Zip.
- The exe is not code-signed, so Windows SmartScreen may ask before it starts the first time.
- Metadata editing (writing tags) is not in this release; the tags are shown, not changed.

Every change, build by build, is in [CHANGELOG.md](https://github.com/Erlbon/dossier/blob/main/CHANGELOG.md).
