Dossier 0.6: an installer that starts in a second, F5 and F4 that go anywhere, an assistant that can work while you are away, and four reviews' worth of everyday gaps closed.

**Two downloads.** `dossier-setup.exe` installs Dossier for you alone (no administrator rights, `%LOCALAPPDATA%\Programs\Dossier`) and starts in under a second. `dossier.exe` is the one-file program as before: nothing to install, but it unpacks itself at every start and takes about three seconds. Windows 10 or 11. Settings stay in your user profile (`dossier.ini`) either way; 0.5 settings carry over.

## What is new since 0.5

- **The installer.** Per user, a Start menu entry, an optional desktop shortcut and an optional `dossier` command on PATH, a clean uninstall, and a silent install (`/VERYSILENT`). An installed copy updates itself through the new installer (Help > Check for Updates), a bare `dossier.exe` by swapping the file, as in 0.5.
- **F5 and F6 to any folder.** The copy box has an editable destination: a folder inside the other panel's (`backup`, made if missing), any path, or for one file a new name (copy as, move as). Options: only files named `*.jpg`, everything into one folder, replace only with a newer file.
- **F4 everywhere.** Edit in another program of your choice (Settings > Opening Files), and edit files on servers and inside zips: Dossier edits a copy and writes it back on every save, but never over a change someone else made meanwhile, and never on a read-only server.
- **The menus were sorted out:** File, Edit, Mark, View, Go, Tools, Network, Settings, Help, each for one kind of thing, with the right-click menu using the same words and the real keys. Ctrl+K finds any command by a few letters.
- **Everyday commander things:** Open With (your programs from the tools bar), Show in Explorer, Unpack and Convert on many archives at once, nested folders with F7 (`a\b\c`), F2 selects the name without its extension, New File opens the editor, a count of folders and files beside the free space, Space adds up a folder's size, Ctrl+Backspace goes to the drive's root, Ctrl+J puts the name under the cursor into the command line, Copy Names as Text, Reopen Closed Tab and a menu on every tab (duplicate, close others, lock), Ctrl+F3 to Ctrl+F6 sort by name, type, date and size, hidden files can be left out (Ctrl+H).
- **File names are coloured by type** (pictures, video and music; archives; documents and code; programs), with hidden files dimmed and marked files still gold. Settings > Appearance > File Colours changes or switches it off.
- **Marking and searching:** Mark by Pattern can also test size, date and attributes ("everything over 1 GB"); Search can skip folders such as `node_modules` and `.git` (also `dossier find --skip`).
- **Batch rename from tags:** `%artist%`, `%album%`, `%title%`, `%track%`, `%series%`, `%number%`, and a photo's `%taken%` date.
- **Compare Two Files** shows two text files side by side, with the differences tinted.
- **Copies are tougher:** they wait for a network or a server that went away, continue a big file where it stopped, and give the folders they make their original times.
- **Servers:** "Allow commands on this server" makes checksums and copies within an SFTP or SCP server run on the server (much faster); without it, or without a shell there, everything works as before.
- **The assistant** (`dossier mcp`) can write manifests and compare folders by checksum, copy only what is missing, use SFTP and SCP folders, and, only if you switch it on, carry out its own plans while you are away from the computer: inside the folders you listed, never overwriting, never deleting for good, and listed for you the next time the window opens.

## Things to know

- **Coming from 0.5:** download this release by hand once (0.5 cannot update itself); from here on Help > Check for Updates does it.
- The installer is new, and so is updating through it: the first update by that route will be to the release after this one. A bare `dossier.exe` updates as before.
- "Let it carry out its own plans without asking" (Settings > Assistant Access) is off by default and only with file changes allowed. A delete that cannot go to a recycle bin always waits for your Run.
- Copying many small files is slower than Explorer (about 550 files a second in a test of 100,000). Folders of that size list, sort and mark in about a second.
- The exe and the installer are not code-signed, so SmartScreen may ask the first time. No Linux build yet.

Every change, build by build, is in [CHANGELOG.md](https://github.com/Erlbon/dossier/blob/main/CHANGELOG.md).
