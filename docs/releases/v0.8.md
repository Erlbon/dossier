Dossier 0.8: covers for comics, films and PDFs in the thumbnail view, SVG drawings in the viewer, and updates that check every file and say why when they cannot.

**Two downloads.** `dossier-setup.exe` installs Dossier for you alone (no administrator rights, `%LOCALAPPDATA%\Programs\Dossier`) and starts in under a second. `dossier.exe` is the one-file program: nothing to install, but it unpacks itself at every start and takes about three seconds. Windows 10 or 11. Settings stay in your user profile (`dossier.ini`); 0.7 settings carry over.

## What is new since 0.7

- **More covers in the thumbnail view.** Comics in RAR, 7z and tar (`.cbr`, `.cb7`, `.cbt`) show their cover as `.cbz` already did, and the cover page a comic's ComicInfo names is the one shown. MKV films show the cover attached to them and MP4 films their stored cover, without ffmpeg. A PDF shows its first page.
- **SVG drawings in the viewer.** F3 shows an SVG as a picture, drawn from the vector so it stays sharp at any zoom; Fit makes a small one (an icon) fill the window. View as Text or Hex shows its XML. Small SVGs fill their thumbnails.
- **Updates you can trust.** Every release now lists its files with their exact size and checksum, and each copy knows how it was put on the PC (installed, or the one-file exe), so Help > Check for Updates never guesses a file name. When a copy cannot update itself, the update box says why, with a Copy Details button, instead of only offering the download page. Each release is now tried before it is offered: the previous release is installed on a test PC, updates itself to the new one and is uninstalled again.
- **The address in Help > About is a link** that opens in the browser.

## Things to know

- **Coming from 0.7:** Help > Check for Updates does it, as before. From 0.8 on, updates go the new way.
- **The exe is bigger: about 64 MB instead of 54 MB.** It is no longer packed with UPX, because Microsoft Defender flags UPX-packed, unsigned programs as malware. Nothing else changed in size.
- The exe and the installer are not code-signed, so SmartScreen may ask the first time. No Linux build yet.

Every change, build by build, is in [CHANGELOG.md](https://github.com/Erlbon/dossier/blob/main/CHANGELOG.md).
