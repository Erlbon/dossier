Dossier 0.13: small fixes to the glass bar. The end of a text now scrolls clear of the bar, the bar can be seen over a pale picture, and `dossier quit` closes a running Dossier, which the installer uses before an update.

**Two downloads.** `dossier-setup.exe` installs Dossier for you alone (no administrator rights, `%LOCALAPPDATA%\Programs\Dossier`) and starts in under a second. `dossier.exe` is the one-file program: nothing to install, but it unpacks itself at every start and takes about three seconds. Windows 10 or 11. Settings stay in your user profile (`dossier.ini`); 0.12 settings carry over.

## New since 0.12

- **The end of a text comes clear of the glass bar.** In the viewer (F3) and the notepad, the text scrolls on past its last line by the height of the bar, so the last lines can be read above it. That empty room is shaded like the line-number column, so it is plain that the file ends there. It is not part of the text: it is never saved or copied.
- **The glass bar can be seen over a pale picture.** The bar, the slider above it, the caption and the short messages now sit on a nearly solid backdrop in the scheme's own colour, so the buttons read on any picture.
- **`dossier quit`** (also `dossier exit` and `dossier --quit`) closes every running Dossier of yours as File > Quit (Ctrl+Q) does, keeping its panels and tabs. A Dossier with unsaved notepad text stays open, and the command names the files. It also closes a running 0.12 or older, with Windows' ordinary close request.
- **The installer asks a running Dossier to quit before an update**, so it saves itself and closes instead of being closed by Windows. Copies from 0.13 on are asked this way.

## Things to know

- **Coming from 0.12:** Help > Check for Updates does it. Close Dossier first, or save any notepad text: 0.12 does not yet understand the installer's request to quit, so the installer closes it the old way.
- The exe and the installer are not code-signed, so SmartScreen may ask the first time.

Every change, build by build, is in [CHANGELOG.md](https://github.com/Erlbon/dossier/blob/main/CHANGELOG.md).
