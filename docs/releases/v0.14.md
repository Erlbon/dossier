Dossier 0.14: columns that fit, colour labels you can see, and tidier menus. With Fit Columns to Panel on, Name keeps real room and its edge can be dragged; dates and Type have a sensible maximum width; a colour label can show as a dot before the name and be set on many items at once.

**Two downloads.** `dossier-setup.exe` installs Dossier for you alone (no administrator rights, `%LOCALAPPDATA%\Programs\Dossier`) and starts in under a second. `dossier.exe` is the one-file program: nothing to install, but it unpacks itself at every start and takes about three seconds. Windows 10 or 11. Settings stay in your user profile (`dossier.ini`); 0.13 settings carry over.

## New since 0.13

- **Fit Columns to Panel gives Name real room.** The other columns shrink to their contents before Name gets narrow, and Name's edge can be dragged: the columns beside it give or take the room. This also works when Name is the last column.
- **Dates and Type have a maximum width.** Date, Created and Last opened share one width, the width of a date; Type is never wider than its longest realistic text. Both follow the font size in Settings. With Fit off they can still be made narrower, never wider.
- **Header texts sit on the left**, also over the right-aligned sizes.
- **Colour labels before the names.** Settings > Appearance > Show Colour Labels (also in the column header's right-click menu) puts a dot in the label's colour before each name in the list. Off unless you switch it on. Right-click > Colour Label sets one label on every marked item at once.
- **Grey examples in empty fields start with "for example:"**, so they cannot be taken for a value already there.
- **Clearer menu names.** Quarantine Settings..., Thumbnail Settings... and Copy and Move Settings... in Settings, apart from the commands of the same name; Colour Scheme; short names in Settings > Opening Files and the Help logs, with the detail in the tooltips; the Enter key is called Enter everywhere (Qt said Return). Compress, Extract Here, Pack to Zip... and Unpack... say in a tooltip which is one click and which asks first.
- **View > Bars** now holds both which bars show and where each one sits (Bar Positions is gone from View).
- **The Home page's Details column** is no longer cut to a date's width.

## Things to know

- **Coming from 0.13:** Help > Check for Updates does it.
- Colour label dots show in the details list only, not in the thumbnail view.
- The exe and the installer are not code-signed, so SmartScreen may ask the first time.

Every change, build by build, is in [CHANGELOG.md](https://github.com/Erlbon/dossier/blob/main/CHANGELOG.md).
