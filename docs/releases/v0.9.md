Dossier 0.9: F3 reads documents, spreadsheets, PDFs and system files; copies can be planned and kept; and two fixes, a blinking top bar and a blank taskbar icon.

**Two downloads.** `dossier-setup.exe` installs Dossier for you alone (no administrator rights, `%LOCALAPPDATA%\Programs\Dossier`) and starts in under a second. `dossier.exe` is the one-file program: nothing to install, but it unpacks itself at every start and takes about three seconds. Windows 10 or 11. Settings stay in your user profile (`dossier.ini`); 0.8 settings carry over.

## What is new since 0.8

- **F3 reads documents.** Word (`.doc`, `.docx`), OpenDocument text, RTF, PowerPoint (`.pptx`, slide by slide with notes) and EPUB (chapter by chapter) show their text. PDFs get their own page view with zoom and find. Enter still opens them in their own program.
- **F3 shows tables as a grid.** Excel (`.xls`, `.xlsx`), OpenDocument spreadsheets, CSV/TSV, SQLite databases (read-only) and torrent files. Select cells and Ctrl+C to paste them into a spreadsheet.
- **Listings for system files.** Windows shortcuts (`.lnk`, with target, times, drive serial and the machine they were made on), Recycle Bin records (`$I` files), property lists (`.plist`), and old archives (ARC, ZOO, ACE, HA, LBR and more) are listed from their headers. An Info panel (I) shows a document's author, dates and editing time.
- **F5 and F6 copy and move at once.** Ctrl+F5 and Ctrl+F6 show the box first, for another destination or other choices. The Ctrl and Shift rows of the function keys are grouped by kind.
- **Planned operations.** Shift+F5 and Shift+F6 put a copy or move on a list instead of running it. Ctrl+F3 opens the list to review, change and run it. A **kept copy** stays on the list to run again, and a rerun copies only what is missing or changed.
- **Git awareness, read-only.** In a git repository the panel's bar shows the branch and what changed, and a Git column marks each file. Dossier never writes to a repository.
- **Follow a log** (F, or the button on the viewer's bar), like `tail -f`.
- **Parts of Windows on the tools bar**: Device Manager, Services, Environment Variables and about twenty more, with their own icons.
- **The address takes `%APPDATA%` and the other Windows variables**, and a file typed there opens in the viewer.
- **A right-click menu on pictures** in the viewer, and an **error log** (Help > Error Log, off by default).

## Fixed

- **The panel's top bar could flicker** at some window widths: the folder count came and went for ever and used a whole CPU core. It now settles.
- **A blank taskbar icon** for an installed copy. The installer's shortcuts now carry Dossier's taskbar id. Updating with the installer fixes the shortcut.
- **Enter in the F5/F6 box cancelled the copy** (and the same in other boxes whose Cancel button came first). Enter now presses the main button.
- **Old Word `.doc` files opened as hex** instead of in Word.

## Things to know

- **Coming from 0.8:** Help > Check for Updates does it.
- The exe and the installer are not code-signed, so SmartScreen may ask the first time. No Linux build yet.

Every change, build by build, is in [CHANGELOG.md](https://github.com/Erlbon/dossier/blob/main/CHANGELOG.md).
