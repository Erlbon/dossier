Dossier 0.11: rename in the row and by editing names as text, Compress and Extract Here in one click, folder rules, What Changed Since..., the Recycle Bin as a place, Eject, Dossier in Windows' Open With, and tabs in the notepad.

**Two downloads.** `dossier-setup.exe` installs Dossier for you alone (no administrator rights, `%LOCALAPPDATA%\Programs\Dossier`) and starts in under a second. `dossier.exe` is the one-file program: nothing to install, but it unpacks itself at every start and takes about three seconds. Windows 10 or 11. Settings stay in your user profile (`dossier.ini`); 0.10 settings carry over.

## Keys that changed

- **Ctrl+F is now Search** in this folder (Alt+F7 still is). Ctrl+F used to be Mark by Pattern.
- **Mark by Pattern is `+` and Unmark by Pattern is `-`** in a panel, the keypad's too. Both are still in the Mark menu; in the command line `+` and `-` type themselves.
- **F2 renames in the row** (the name becomes a text field, the part before the extension selected; Enter keeps it, Esc cancels), and **New Folder** (F7, Ctrl+Shift+N) makes "New Folder" at once and leaves its name open for typing. Ctrl+Z undoes both.
- **Ctrl+E** puts the cursor in the command line.

## What is new since 0.10

- **Compress and Extract Here** (right-click, and Tools > Archives) in one click, no box: a zip beside the items, or each archive unpacked where it stands, into a folder of its own name when it holds more than one item.
- **Edit the Names as Text** (Tools > Batch Rename): the marked names open one per line in the notepad; edit, save and close, and the plan lists every rename with Run and Close. One Ctrl+Z puts them all back.
- **Folder rules** (Tools > Rules > Folder Rules...): a folder can have rules (name patterns, age, size; move, copy or delete to the Recycle Bin). They never act alone: the status line says "Rules for this folder would move 3 items. Show the Plan", and nothing changes until you press Run.
- **What Changed Since...** (Tools > Compare): Remember This Folder's State keeps size, time and checksum of every file below a folder in Dossier's own settings folder; later, What Changed Since... lists what was added, changed, moved or removed.
- **Earlier Versions...** (right-click, or Tools > Compare) finds a file or folder in a NAS, ZFS or btrfs snapshot folder above it and opens that moment in the other panel. Snapshot folders are read-only in Dossier.
- **The Recycle Bin is a place on the Home page**: each item by its original name, where it came from and when it was deleted. Right-click: Put Back, Delete for Good, Empty the Recycle Bin.
- **Eject** removable drives, discs and mapped drives from the drive menu, the Home page and Go > Eject This Drive. Dossier's own copies to the drive finish first.
- **Dossier in Windows' Open With** (Settings > Opening Files, and two ticks in the installer): the picture viewer for pictures, the notepad for text files. Open Default Apps... takes you to Windows' page for "Always". The general "Dossier" entry opens a picture in the viewer and text in the notepad. A moved `dossier.exe` takes the switches over by itself.
- **Tabs in the notepad**: F4 on several marked files opens them as tabs in one window; `dossier edit` and Open With from Explorer add tabs to the running notepad. Both notepads notice when another program changed the file and ask whether to reload.
- **Folders spring open while dragging**: hold dragged files over a folder, a tab or a Home page drive for about a second. If nothing is dropped, the panel goes back. Settings > Open Folders While Dragging Over Them switches it off.
- **A sidebar of places** (View > Bars > Sidebar, hidden by default): pinned folders, drives, servers and the Recycle Bin at the left of both panels.
- **Send to Device** (right-click): sends files to one of your own Tailscale devices with Taildrop. The Home page's Tailnet group has **Fetch files sent to you...**, shown as a move into a folder you choose.
- **Find Duplicate Files > Replace with Clones...** on ReFS volumes (greyed on NTFS, with a tooltip saying why).
- **Copy Paths as Text is now called Copy Path**, in the right-click and Edit menus alike.
- **Settings > Typing in a Panel** chooses whether a typed letter jumps to a name or goes to the command line (Windows keeps the command line).
- Menus: View > Bars holds the Tools Bar and the Sidebar; File > Preview holds View, View as Glass and Quick Look; Go has Parent Folder and a Drives submenu.

## Things to know

- **Coming from 0.10:** Help > Check for Updates does it.
- The exe and the installer are not code-signed, so SmartScreen may ask the first time.
- **Not yet tried by hand on Windows:** Eject on a real USB stick, the Open With entries in a real Explorer list, Replace with Clones on a real ReFS volume, and Taildrop against a real Tailscale. The tests cover them with stand-ins.
- **Mac and Linux:** this release has a lot of Mac and Linux work (Finder's and the Linux desktops' keys, Quick Look, permissions, launchers, the desktop's shares and phones, Open With from the system). The test builds for a Mac and Linux are still made separately for testers and are not part of this release.

Every change, build by build, is in [CHANGELOG.md](https://github.com/Erlbon/dossier/blob/main/CHANGELOG.md).
