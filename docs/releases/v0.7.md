Dossier 0.7: copies that finish what they started, servers that come back by themselves, a folder tree, and a Share column for Folder Sizes.

**Two downloads.** `dossier-setup.exe` installs Dossier for you alone (no administrator rights, `%LOCALAPPDATA%\Programs\Dossier`) and starts in under a second. `dossier.exe` is the one-file program: nothing to install, but it unpacks itself at every start and takes about three seconds. Windows 10 or 11. Settings stay in your user profile (`dossier.ini`); 0.6 settings carry over.

## What is new since 0.6

- **Finish the job.** The copy box has "Skip what is already there and the same": a second run after a copy that stopped copies only what is missing or changed, with no questions. The same means the same size and time (a file exactly one hour off after a summer-time change counts as the same); with Verify on, the same bytes. Cancel stops it at any point.
- **Servers come back by themselves.** When an SFTP, SCP or FTP connection drops in the middle of a copy, Dossier connects again with the saved login and carries on; it never asks. If the server refuses that login, it tries once and stops, so a server that blocks addresses after failed logins never blocks you. A server you disconnect stays disconnected.
- **Export Log.** After a big job (500 steps, 1 GB or a minute), Tools > Operations > Export Log... saves every step as a Markdown table: path, size, result, retries and seconds. Nothing is written unless you ask.
- **A bar for the file and one for the whole job.** While a big file is copied, the copy box shows its own bar, speed and time left above the bar for the whole job; and the box has a Pause button.
- **Big copies to and from servers go on where they stopped.** A file of 64 MB and up copied to or from an SFTP, SCP or FTP server continues from where the connection broke, as copies between local disks already did, after checking that what is already there matches the original.
- **Small files copy about twice as fast** (1,700 files a second where 0.6 did 820, timed on 10,000 files on one disk). A small new file is now copied by Windows' own copy straight to its name, as Explorer does; a file that replaces another still goes through a temporary file, so it is never touched before the new one is whole.
- **7z without installing anything.** The program now opens, browses and unpacks 7z archives by itself. RAR, ISO, tar and the other formats still need 7-Zip, or now also **NanaZip** from the Microsoft Store, which Dossier did not find before.
- **Folder Tree** (Go > Folder Tree..., Alt+F10): the folders of the drive as a tree in a popup; Enter goes there.
- **Share column.** After Folder Sizes, the Share column shows each item's part of the folder in percent. It is hidden at first: right-click a column header to show it.

## Things to know

- **Coming from 0.6:** Help > Check for Updates does it. An installed copy updates by running the new installer silently; this is the first update by that route.
- Reconnecting uses only a saved login (a key, the ssh agent or a stored password). A connection that needs a question stays closed until you connect again.
- The exe and the installer are not code-signed, so SmartScreen may ask the first time. No Linux build yet.

Every change, build by build, is in [CHANGELOG.md](https://github.com/Erlbon/dossier/blob/main/CHANGELOG.md).
