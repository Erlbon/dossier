Dossier 0.5: the glass look, Google Drive, a Health window and the first metadata writing.

**Download `dossier.exe`**, one file, nothing to install. Windows 10 or 11. Settings stay in your user profile (`dossier.ini`) as before; 0.4 settings carry over.

## What is new since 0.4

- **The glass look.** `dossier view picture.jpg` (or **Files > View as Glass**) opens a stand-alone picture viewer over the screen with the desktop showing through: **frosted**, **dim** or **solid**, with a fallback when the computer cannot do the look. The file manager, the F3 viewer and the F4 notepad can have a frosted frame too (Settings > Appearance; the lists stay solid), with a frosted title bar on Windows 11.
- **Floating bars** in the picture viewer, the text viewer and the notepad: one bar that fades in when the mouse moves, instead of menus, toolbars and status lines.
- **Google Drive as a folder:** sign in through your browser (Dossier never sees your Google password). My Drive, Shared with me and Shared drives; Google Docs, Sheets and Slides show as .docx, .xlsx and .pptx. Delete goes to Drive's bin. Needs a one-time setup of your own Google client ID; the dialog explains it.
- **Nextcloud** preset under Remote sources.
- **A network share that wants a login asks for one**, with Windows' own sign-in dialog.
- **File health:** `dossier check` and the **Health window** (findings grouped by rule, preview and fix, mark, ignore), with an optional quarantine folder.
- **Writing metadata, first step:** mp3 tags and cbz ComicInfo can be edited in the Metadata tab of Properties, and with `dossier tag`.
- **All twelve function keys**, set in a table (plain, Shift and Ctrl) under Settings > Function Keys; F12 opens a terminal, or an SSH session on an SFTP/SCP server's folder.
- **Resume after a restart:** file jobs are remembered step by step and can be picked up again; failed jobs are kept.
- **Command line:** name completion (Ctrl+Space) and a history list (Ctrl+Down). **Saved tab sets** (View > Tabs). **Change Dates and Attributes** and **New Link** dialogs (`dossier touch`, `dossier link`).
- **Paste or drop a picture, text or web link** to make it a file; drag files out of archives and servers.
- **Notepad:** Markdown preview, opt-in syntax highlighting and code folding.
- Smaller things: auto refresh with its own switch for network drives, double-click the address bar to edit the path, Unpack suggests a folder beside the archive, moved files are no longer left marked, Help menu links to the documentation.

## Things to know

- The glass look is new; a remote desktop session always gets solid. Say if a look is wrong on your screen.
- Google Drive is new; other cloud drives (Dropbox, OneDrive) are not in this release.
- Metadata writing covers mp3 and cbz only; video files are still read only.
- The remote servers have been tested against test servers more than real ones. The exe is not code-signed, so SmartScreen may ask the first time. No Linux build yet.

Every change, build by build, is in [CHANGELOG.md](https://github.com/Erlbon/dossier/blob/main/CHANGELOG.md).
